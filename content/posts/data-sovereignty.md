# 数据主权：为什么数据应该留在家里

## 厂商云的问题：数据归属权在厂商，不在你

**数据存在厂商的服务器上**：
- 米家云、美的云、涂鸦云……
- 厂商可以限流、改接口、停服
- 你的家庭活动数据，别人比你更清楚

**具体风险**：
- **云停服**：数据直接不可用（历史数据可能永久丢失）
- **限流**：高频采集被限制（"每分钟最多 60 次"）
- **改接口**：API 变更导致你的采集器失效
- **隐私**：你的作息、活动、习惯，厂商比你更清楚

**这不是"可能会发生"，是"一定会发生"**。厂商云的本质是"数据托管"，不是"数据服务"——你只有使用权，没有所有权。

## 家庭数据是最隐私的数据

**家庭数据比你想的更敏感**：
- 什么时候睡觉、什么时候起床
- 什么时候洗澡、洗多久
- 什么时候出门、什么时候回家
- 老人夜间是否起夜、孩子是否在家

**这些数据一旦上云，就等于把家庭生活完全暴露给厂商**。

**为什么家庭数据比个人数据更敏感**：
- 个人数据（心率、位置）只涉及你一个人
- 家庭数据涉及**全家人**（老人、孩子、访客）
- 家庭数据可以推断**生活习惯**（几点洗澡、几点睡觉、是否在家）
- 家庭数据可以推断**健康状况**（老人夜间起夜频率、活动能力）

## 留在家里：数据主权在自己手里

```
能直采就直采，能不经过云就不经过云。

直采的好处：
- 数据主权在自己手里
- 断网也能用（本地分析不依赖云）
- 可以按自己的意愿保留/删除/分析
- 不需要向厂商申请权限、担心限流
```

**实测案例**：
- 泵的 BLE 数据通过自研 ESP32 网关直采，43 个字段完整
- 电表通过 ESPHome 直发 MQTT，原始裸值无损失
- 温湿度传感器通过 HA 本地接入，不经过米家云

**关键**：直采不仅是为了"数据完整"，更是为了"数据主权"。

## 去中心化的价值

**去中心化不是技术潮流，是数据主权的必然选择**：

| 方面 | 厂商云 | 家庭侧 |
|---|---|---|
| 数据归属 | 厂商 | **自己** |
| 可用性 | 依赖云 | **本地可用** |
| 隐私 | 暴露给厂商 | **自己控制** |
| 保留期 | 厂商决定 | **自己决定** |
| 分析能力 | 厂商限制 | **完全自由** |

**为什么去中心化是"必然选择"**：
- 家庭数据是最隐私的数据，不能交给第三方
- 厂商云随时可能停服/限流/改接口
- **只有数据留在家里，你才真正拥有它**

## 数据主权的三个层次

### 层次 1：数据不离开家

**原则**：数据只存在家里的设备上，不经过任何云。

```
设备 → 家庭网关/HA → 本地数据库 → 本地分析
```

**好处**：
- 数据主权完全在自己手里
- 断网也能用（本地分析不依赖云）
- 隐私完全自己控制

### 层次 2：数据可以出云，但你有选择权

**原则**：数据可以备份到云（如 Cloudflare R2），但**你有选择权**——选哪家、存多久、怎么删。

```
家庭数据 → 本地数据库 → 你选择备份到云（可选）
```

**关键**：**你有选择权**，不是"必须上云"。你可以选择：
- 备份到 Cloudflare R2（你控制的对象存储）
- 备份到自己的 VPS
- 不备份到云（纯本地）

### 层次 3：分析在本地，不是"云分析"

**原则**：数据分析在本地完成，不是把数据上传到云再分析。

```
本地数据库 → 本地分析/Grafana → 本地展示
```

**好处**：
- 分析逻辑自己控制（不依赖厂商的算法）
- 分析结果自己拥有（不是"云分析结果"）
- 可以随时修改分析方式（不用申请权限）

## 通用原则

**家庭数据是最不该上云的数据**：

- 能直采就直采（设备协议可达就直采）
- 能不经过云就不经过云（HA 本地接入、自研网关）
- 数据主权比便利性重要（宁可多维护一个采集器，也不把数据交给厂商）

**数据主权不是技术选择，是生活方式选择**：
- 你愿不愿意让厂商知道你的作息？
- 你愿不愿意让厂商控制你的数据？
- 你愿不愿意依赖厂商的云服务？

**如果不愿意，就把数据留在家里**。

## 误区与边界

### 误区 1：以为"云备份更安全"

实际上：
- 云停服 = 数据永久丢失
- 云限流 = 高频采集被限制
- 云改接口 = 采集器失效

**"云更安全"是错觉**——你把数据主权交给了别人。

### 误区 2：以为"厂商会保护我的隐私"

实际上：
- 厂商可以分析你的数据（用于产品改进、广告、模型训练）
- 厂商可以分享你的数据（合作伙伴、第三方）
- 厂商可以修改隐私政策（你同意了就等于授权）

**"厂商会保护隐私"是承诺，不是保障**。

### 边界：什么时候可以用云

- **你有选择权的云**（如 Cloudflare R2、自己的 VPS）→ 可以用
- **你完全控制的云**（你拥有 root 权限）→ 可以用
- **厂商云**（米家云、美的云）→ **避免**（数据主权不在你手里）

## 原则提炼

1. **数据主权在自己手里**：能直采就直采，能不经过云就不经过云
2. **家庭数据是最隐私的数据**：涉及全家人、生活习惯、健康状况
3. **去中心化是必然选择**：不是技术潮流，是数据主权的必然要求
4. **你有选择权才是好云**：Cloudflare R2/自己的 VPS 可以用，厂商云避免

**数据主权不是技术选择，是生活方式选择**。家庭数据是最不该上云的数据。
